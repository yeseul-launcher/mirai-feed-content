# MIRAI Feed Content

MIRAI Feed 탭용 이미지 생성 프롬프트 + 캡션 + 장소 라이브러리. 총 100개 캐릭터.

- `PROMPTS.md`: 전체 프롬프트/캡션/장소 텍스트 (배치별 정리)
- `mirai-feed-prompts.html`: 브라우저에서 바로 열어보는 버전, 프롬프트 옆 복사 버튼 포함
- `reference-images/`: 캐릭터별 원본 썸네일(외형 참고용). 일부 배치(v7~v9, v11)는 원본 이미지가 소실되어 텍스트만 남아있음.

## 사용법

`mirai-feed-prompts.html`을 더블클릭해서 브라우저로 열면 됨. 로그인 불필요, 로컬 파일.
